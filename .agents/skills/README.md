|---|---|---|
| [ppt-studio](./ppt-studio/SKILL.md) | 输入内容 + 风格 + 页数，生成可编辑 `.pptx`；风格：`apple` / `free` / `taobao` / `gov` | 直接说「做份 PPT，主题 XXX，苹果风，10 页」 |

## 新增技能

1. 新建 `技能名/SKILL.md`，开头写：

   ```
   ---
   name: 技能名
   description: 干什么、什么时候用
   ---
   ```

2. 在上面的表格里加一行。

重启会话后生效。
